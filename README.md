# 命令快捷方式

`命令快捷方式` 是一个 VS Code 插件，用来在侧边栏集中维护常用终端命令，并一键发送到终端执行。

它适合放一些高频但不想反复手敲的命令，比如启动本地服务、运行测试、执行构建、清理缓存，或者进入固定目录后再执行一串命令。

## 主要功能

- 在活动栏提供独立入口
- 平铺展示全部命令，便于快速查看
- 支持切换排序方式，并记住上次选择
- 支持新增、编辑、删除命令
- 支持一键执行命令
- 命令列表会自动保存在扩展本地状态中
- 执行命令时只复用明确空闲的终端；如果当前终端正在运行或状态未知，会自动新建终端

## 使用说明

### 打开插件

安装后，活动栏会出现 `命令快捷方式` 图标。点击后可以看到 `命令列表` 视图。

### 新增命令

1. 点击视图标题栏上的 `新增` 按钮
2. 输入命令名称
3. 输入实际要执行的终端命令

示例：

- 名称：`启动前端`
- 命令：`npm run dev`

### 执行命令

在命令列表中点击某条命令右侧的 `执行` 按钮，插件会把这条命令直接发送到终端。

说明：

- 如果当前活动终端处于明确空闲状态，会优先复用它
- 如果当前活动终端正在运行命令，或扩展无法确认它是否空闲，会自动创建一个新终端
- 如果当前没有终端，插件会自动创建一个新终端
- 命令会直接发送并执行，不会额外弹出确认

### 编辑命令

点击某条命令右侧的 `编辑` 按钮，可以修改：

- 命令名称
- 实际执行的终端命令

### 删除命令

点击某条命令右侧的 `删除` 按钮后，会弹出确认框，确认后才会删除。

### 刷新列表

点击视图标题栏上的 `刷新` 按钮，可以手动刷新当前命令列表。

### 切换排序

点击视图标题栏上的 `排序` 按钮，可以选择以下排序方式：

- 名称正序
- 名称倒序
- 命令正序
- 命令倒序
- 时间正序
- 时间倒序

插件会记住你上一次选择的排序方式，下次打开编辑器后仍然会按该方式显示。

## 适用场景

- 经常执行固定的开发命令
- 需要把项目常用命令收敛到一个地方
- 不想每次都打开历史终端记录去翻以前执行过的命令
- 希望用更直观的方式管理常用命令，而不是单纯依赖 shell history

## 注意事项

- 插件不会解析或改写你的命令内容，会按你填写的原样发送到终端
- 命令是否能成功执行，取决于当前工作区、终端环境和本机依赖
- 删除命令后无法自动恢复，建议不要随手清理仍在使用的命令
